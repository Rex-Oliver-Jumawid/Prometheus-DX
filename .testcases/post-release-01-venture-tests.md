- Reject direct and indirect parent cycles, including concurrent requests.

- Verify Team/Schedule/Reports multi-membership filtering counts each person once per view.
- Preserve existing primary/focus/project/outcome/chat IDs when upgrading the database.
- Confirm browser-role database access to membership/audit tables is denied.
- Verify refreshed pages, direct navigation, readable errors, keyboard operation, and mobile layout.
- Regress existing Registry invitations, project workflows, work sessions, collaboration, and device-push targeting.
